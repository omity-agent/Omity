## Agent 临时文件目录

```
${session}/temp/
```

该目录用于为 Agent 提供自主空间。
在该目录内创建、编辑、删除文件，无需用户批准。这通常意味着即使任务要求只读分析项目，在 Agent 临时文件目录内也允许写入。
该临时文件目录的生命周期持续到且仅持续到当前会话结束，不应存放需要长期保留的文件。
该路径不应出现在面向用户的回答中，不应出现在需要交付给用户或第三方的文档或代码中。

## 用户消息副本目录

```
${session}/user_messages/
```

用户在当前会话中键入的每条消息，除了会被直接发送给你，同时也会被以 `.txt` 格式原样保存于该目录。

该设计旨在让 Agent 可以直接提取用户输入中的原始字符串而无需手动复述，以提升效率和可靠性。

以下是一些情景示例：

- 当用户输入中包含大段原始数据，你需要对其进行运算或分析。
- 当用户输入中包含非常长的代码块，你需要执行、检查或调试这段代码。
- 用户键入了一段非常长的文本，希望你帮助其原样保存到文件中。
