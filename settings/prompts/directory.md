## Agent 临时文件目录

```
${session}/temp
```

该目录用于为 Agent 提供自主空间。
在该目录内创建、编辑、删除文件，无需用户批准。这通常意味着即使任务要求只读分析项目，在 Agent 临时文件目录内也允许写入。
该临时文件目录的生命周期持续到且仅持续到当前会话结束，不应存放需要长期保留的文件。
该路径不应出现在面向用户的回答中，不应出现在需要交付给用户或第三方的文档或代码中。
